# SatvikMeals - Pure Vegetarian Tiffin Service

A complete subscription-based meal delivery platform with:
- Google Authentication
- Multiple meal plans (Satvik/Regular)
- Breakfast, Lunch, Dinner options
- Coins & Referral system (100 coins for referrals)
- Admin panel with menu editor
- Instamojo payment integration
- Telegram notifications

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: Google OAuth
- Payments: Instamojo
